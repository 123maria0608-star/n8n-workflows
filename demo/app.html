Search

The page POSTs { q, mode } to /webhook/docs/search. That workflow runs one SQL statement against Postgres: keyword mode uses websearch_to_tsquery, ts_rank_cd and ts_headline; exact mode uses ILIKE. The PDFs were indexed by workflow 10 (Read files → Extract from File → chunk → INSERT).

Open PDF

GET /webhook/docs/file?name=x.pdf checks the name against the index, reads the file from disk, and responds with the binary and Content-Type: application/pdf. The page fetches that and draws every page with PDF.js, so the whole document shows without depending on a browser plugin. The same URL opens in a new tab as a normal PDF.
